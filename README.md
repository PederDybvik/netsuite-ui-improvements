## Current Features

- SuiteScript error formatting
- JSON in text field formatting
- Adds loading overlay
- UI fixes:
  - Gray box around tables on record, so you si if value is outside or inside of section.
  - SubTabs and SubSubTabs have gotten a bigger hit-box and a hover state.

This extension is mainly created to work with NetSuites Redwood UI.
